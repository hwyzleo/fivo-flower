## 1. 产品定义

FIVO 的花花是一款个人植物养护与花园资产管理应用。用户通过手动录入或订单截图建立植物档案，持续记录生长状态、照片、养护动作和日志，并管理工具资材、花园账目及植物生长统计；AI 小花灵提供植物识别、订单信息解析和养护问答。

### 1.1 产品目标

1. 让每株植物都有完整、可追溯的生命档案。
2. 降低购买信息、养护动作和生长变化的记录成本。
3. 统一掌握植物、工具资材和花园投入。
4. 在保护本地数据控制权的前提下提供 AI 辅助。

### 1.2 首版原则

- 个人单用户、无需注册、本地优先。
- iPhone 竖屏、简体中文、SwiftUI、浅色模式优先。
- 除 AI 联网能力外，核心记录功能均可离线使用。
- AI 识别结果必须可编辑，不得未经确认直接写入正式档案。
- 页面布局以易用性为准；`ui.png` 仅作为 Tactile Soft UI 视觉参考。

## 2. 首版范围

### 2.1 包含

- 花房首页、植物分类与状态筛选。
- 植物手动新增、编辑、归档、恢复和删除。
- 订单截图 OCR/AI 辅助导入。
- 植物封面、照片、生长状态及计时。
- 预设和自定义养护动作、长按多选与批量养护、提醒及养护日历。
- 自动与手动植物日志、全局档案日志。
- 工具资材档案、消耗品库存和设备手动状态。
- 花园账本、自动采购账目、手动记账和统计。
- 植物出花梗及开花统计。
- AI 植物识别和养护问答。
- 本地备份与恢复、植物和账本 CSV 导出。

### 2.2 首版不包含

- 注册登录、多人共享、公开社区和电商。
- iCloud 自动同步；仅预留架构与数据迁移能力。
- 补光灯、通风设备、灌溉设备等真实硬件控制。
- 深色模式的完整视觉适配。
- 日志图片/PDF 导出、植物档案 PDF。
- iPad、macOS、Android 和 Apple Watch 专版。
- 自动判定植物死亡、疾病诊断或 AI 结果自动落库。

## 4. 核心业务规则

### 4.1 植物生命状态与分类

生命状态分为 `存活`、`死亡`、`赠送`，默认存活。分类由购买日期和生命状态计算，不允许用户直接修改分类值。

| 展示分类 | 规则 |
|---|---|
| 活 1 年 | 存活，且购买日期距当前不足 1 年 |
| 活 2 年 | 存活，且已满 1 年、不足 2 年 |
| 活大于 2 年 | 存活，且已满 2 年 |
| 死了 | 已手动标记死亡 |
| 送了 | 已手动标记赠送 |
| 未分类 | 存活，但购买日期为空 |

- 周年按用户当前时区的日历日期计算，不按固定 365 天处理。
- 标记死亡或赠送时必须填写日期；默认当天，不允许晚于当前日期，也不允许早于购买日期。
- 死亡和赠送植物保留完整档案，可查看、筛选和恢复。
- 恢复用于纠正误操作：清除对应死亡/赠送信息并重新计算分类及陪伴天数。

### 4.2 生长状态

首版每株植物同一时刻只有一个当前生长状态：

- 养叶养根：新增植物时的默认状态。
- 出花梗。
- 开花。
- 用户自定义状态。

切换状态时，上一状态记录结束，新状态记录开始；历史记录不可被覆盖。死亡或赠送时结束当前状态。恢复后新建“养叶养根”状态，原历史保留。

### 4.3 天数与统计口径

- 所有进行中天数采用自然日计数，开始当天计为第 1 天。
- 已陪伴天数：购买日期至今天；死亡或赠送时计算至对应日期。购买日期为空时不显示具体天数。
- 已养叶养根/出花梗/开花天数：当前对应状态的开始日期至今天。
- 状态已结束后显示该段历史时长，不继续累加。
- 出花梗间隔：同一植物相邻两次出花梗开始日期之间的自然日差。
- 出花梗频率：选定统计周期内出花梗次数；有间隔数据时可展示平均间隔。
- 开花时长：一段开花状态从开始日至结束日的包含式自然日数。
- 平均开花时长只使用已结束的有效记录；进行中的开花单独展示，不参与平均值。
- 未来日期不得参与计时或统计。

### 4.4 金额口径

- 默认币种为人民币，金额最多两位小数，不得为负数。
- “入手价”是植物档案字段；“账目金额”属于交易记录。
- “累计投入” = 有效采购及其他支出 − 关联退款，不表示当前资产估值。
- 普通收入单独统计，不自动冲减累计投入；退款必须关联原支出时才冲减对应投入。
- 删除植物或工具档案时，默认保留相关账目并解除档案关联，避免财务记录丢失。

## 5. 功能需求与验收标准

### 5.1 花房首页

**FR-HOME-001** 展示植物分类入口及对应数量，支持“全部”和“未分类”。

**FR-HOME-002** 支持按生长状态、平台、摆放位置组合筛选，并可一键清除筛选。

**FR-HOME-003** 支持按品种名称、别名、植物编号、店名搜索。

**FR-HOME-004** 植物卡片至少展示封面、名称、分类、当前状态、陪伴天数和摆放位置；无封面时显示统一占位图。

**FR-HOME-005** 支持按最近更新、购买日期和名称排序。

**FR-HOME-006** 右上角仅提供 AI 小花灵和设置入口，不再提供独立提醒中心。

**FR-HOME-007** 长按植物卡片进入多选模式，可继续选择或取消选择多株植物，并对所选植物发起批量养护；多选模式可退出，批量养护沿用 FR-CARE-004 的独立记录与批次规则。

**验收**：创建不同年龄、生命状态和生长状态的植物后，数量、筛选结果和卡片信息符合第 4 节规则；空花房和空筛选结果均有明确引导；长按多选不会误入植物详情，所选植物数量与批量养护页一致。

### 5.2 植物档案

**FR-PLANT-001** 手动新增植物，字段包括：

- 必填：品种名称。
- 可选：别名、植物编号、规格、购买日期、入手价、平台、店名、来源链接。
- 可选：植料、摆放位置、备注、封面和订单原始截图。
- 系统字段：生命状态、当前生长状态、创建/更新时间。

手动新增时可选择“同时生成采购账目”，默认关闭；开启且入手价大于 0 时，在同一事务中生成关联植物的采购支出，金额为空或为 0 时不生成零金额账目。

初始生长状态提供“设置开始日期”开关，默认关闭并使用创建当天；开启后可选择今天或过去日期，按所选自然日开始首段状态及持续天数计算，不允许未来日期。状态开始日期不改变档案创建时间。

**FR-PLANT-002** 支持编辑全部用户字段、查看详情和复制档案。复制时创建新 ID，默认不复制日志、养护、状态历史和账目；入手价默认清空，避免重复计算。

**FR-PLANT-003** 支持标记死亡、赠送及恢复，记录对应日期、原因和可选接收人。

**FR-PLANT-004** 删除必须二次确认，并明确照片、日志、提醒及账目的处理方式。

**FR-PLANT-005** 用户可从该植物任意照片中选择封面，并进行移动、缩放和方形裁剪；更换封面不删除原照片。

**验收**：必填校验、日期校验、金额校验和链接格式提示有效；复制、归档、恢复和删除不会造成状态历史或账目误覆盖。

### 5.3 订单截图导入

**FR-IMPORT-001** 可从相册选择一张或多张订单截图，也可在拍摄后导入。

**FR-IMPORT-002** 使用设备端 OCR 提取文本，并尝试解析购买日期、支付金额、平台、店名、商品标题和订单号；配置 AI 后可增强品种名称及字段解析。

**FR-IMPORT-003** 必须进入可编辑确认页，标出低置信度或缺失字段，用户确认后才创建植物。

**FR-IMPORT-004** 原始截图可查看、替换和删除；删除截图不删除已创建的植物。

**FR-IMPORT-005** 识别失败或无网络时仍可通过 OCR 结果和手动输入完成新增。

**FR-IMPORT-006** 用户可选择是否同时生成采购账目，默认开启；未填写金额时不生成零金额账目。

**FR-IMPORT-007** 根据订单号和已导入截图进行重复提示，但允许用户确认继续。

**验收**：成功、部分识别、完全失败、重复截图、取消导入和生成账目六类路径均可完成，且未确认前不产生正式数据。

### 5.4 生长状态与照片

**FR-GROWTH-001** 详情页展示当前生长状态、开始日期、持续天数和陪伴天数。

**FR-GROWTH-002** 用户可切换状态并补充日期、备注和照片；开始日期默认当前时间，可选择合理的过去日期。

**FR-GROWTH-003** 可查看完整状态历史；可更正历史记录的起止时间和备注，保存时校验同株状态时间不得重叠并重新计算统计，同时保留更新时间。

**FR-PHOTO-001** 支持在任意生长状态、养护动作或手动日志中添加多张照片。

**FR-PHOTO-002** 照片支持全屏查看、拍摄时间、备注、设封面和删除；删除被设为封面的照片后自动使用占位图或选择其他照片。

**验收**：多次切换状态后只有一段进行中记录；跨月、跨年和闰年的天数正确；照片与对应状态或日志关联准确。

### 5.5 养护动作与提醒

**FR-CARE-001** 内置换盆、修剪、浇水、施肥、杀虫、杀菌、其他，可停用或调整排序。

**FR-CARE-002** 可新增、重命名和删除自定义动作类型；已被历史记录使用的类型删除后，历史名称仍须保留。

**FR-CARE-003** 每次养护记录时间、动作、植物、文字、用量/单位和照片，除植物和动作外均可为空。

**FR-CARE-004** 支持一次选择多株植物执行同一动作；系统为每株植物生成独立记录，并保留批次标识。

**FR-CARE-005** 周期仅支持每 N 天、每 N 周、每 N 月、每 N 年，N 为不小于 1 的整数，不支持仅一次或按指定星期。每 N 月/年按日历计算，目标月没有同日时取目标月最后一天。旧仅一次及按星期周期不做兼容，启动时清理；已有有效每 N 天周期保留。

**FR-CARE-006** 当前待办只有在完成时才生成下一次待办，不再提供跳过操作。日历完成同时生成养护记录；修改周期只调整当前未完成待办，不重写历史。存在最近养护记录时按“最近养护时间 + 新周期”计算，否则按“周期创建时间 + 新周期”计算。

**FR-CARE-007** 未授权系统通知时仍显示应用内待办，并引导用户开启通知。

**FR-CARE-008** 植物详情在“已陪伴”和“当前生长状态”之间展示“当前养护状态”，按启用的养护动作分别展示最近一次操作时间及下一次待办时间，无操作记录显示“未记录”，无有效周期显示“未设置下次待办”。每个动作右侧始终显示“设置周期”，并作为添加/修改周期的唯一入口；无周期时进入添加页，有未完成周期时进入修改页，默认选中当前植物、对应动作及同名标题。

**FR-CARE-009** 底部“日历”按自然日展示待处理周期待办，支持切换月份和日期、查看并完成当日待办，不提供新建周期或跳过按钮。月历中有待办的日期必须在日期数字下方显示待办数量，并以轻量背景色区别于无待办日期。低库存提醒不混入养护日历。

**FR-CARE-010** 手动添加单株或批量养护时，若某株植物对应动作存在未完成待办，则将最早一条待办视为本次完成，与实际养护记录在同一事务中生成下一条待办。下一次时间按“实际养护操作时间 + 当前周期”计算，不要求用户先在日历点击完成。

**验收**：批量记录可独立查看；完成待办后下次时间正确，未完成时不提前生成后续待办；修改周期自动调整当前待办；手动及批量养护自动完成对应待办；修改系统时间或重启设备不会造成重复记录；养护状态与日志、周期一致，日历仅展示所选日期的待办。

### 5.6 植物日志与全局档案日志

**FR-JOURNAL-001** 以下行为自动生成日志：状态变化、养护动作、添加照片、标记死亡/赠送、恢复及保存资料修改。

**FR-JOURNAL-002** 用户可添加手动日志，包含时间、文字和多张照片。

**FR-JOURNAL-003** 单株详情提供时间线，全局“档案日志”聚合所有植物记录。

**FR-JOURNAL-004** 支持按植物、日志类型和日期范围筛选，按时间倒序展示。

**FR-JOURNAL-005** 自动日志关联源记录；源记录删除时同步处理关联日志，手动日志不受影响。

**FR-JOURNAL-006** 单株详情的日志列表中，有关联图片时在卡片右侧展示第一张图片缩略图，多于一张时同时展示图片总数；无图片时不保留缩略图占位。点击日志进入只读详情，查看完整时间、文字和关联图片，图片可进入全屏浏览。

**验收**：所有关键行为均有且只有一条对应日志，不出现重复日志；全局筛选与单株时间线结果一致；手动、养护和状态日志的图片数量及详情关联准确。

### 5.7 工具与资材

**FR-TOOL-001** 分类至少包括花盆、补光灯、通风设备、标签、塑形工具、植料、浇水瓶和其他，支持统一“其他”补充。

**FR-TOOL-002** 档案字段包括名称、分类、品牌、规格、购买日期、价格、数量、位置、照片和备注。

**FR-TOOL-003** 植料等消耗品可记录当前库存、单位和低库存阈值；库存调整保留时间和备注。

**FR-TOOL-004** 低库存工具在工具库和提醒中心可见，可关闭单个提醒。

**FR-TOOL-005** 补光灯、通风设备等仅支持手动标记使用中/关闭，不宣称已连接或控制真实设备。

**FR-TOOL-006** 创建工具时可选择自动生成采购账目。

**验收**：消耗品和设备显示对应字段；手动开关只改变本地展示状态；删除工具默认保留相关账目。

### 5.8 花园账本

**FR-LEDGER-001** 展示累计投入、植物投入、工具资材投入及所选周期支出。

**FR-LEDGER-002** 支持手动新增支出、收入和退款，字段包括标题、分类、金额、日期、平台/店名、关联植物或工具、备注。

**FR-LEDGER-003** 支持搜索、编辑、删除，以及按月份、年度和分类筛选。

**FR-LEDGER-004** 植物或工具创建时自动生成的账目具有明确来源，可跳转回原档案。

**FR-LEDGER-005** 修改档案价格时不得静默修改账本；用户须明确选择同步更新关联采购账目。

**FR-LEDGER-006** 支持分类汇总和月度趋势，金额、退款和收入按第 4.4 节口径计算。

**验收**：自动与手动账目均计入正确分类；退款、删除档案、修改价格和跨周期筛选不会产生重复或错误汇总。

### 5.9 植物统计

**FR-STATS-001** 单株统计展示出花梗次数、平均出花梗间隔、最近出花梗日期、开花次数、最近/平均/最长开花时长。

**FR-STATS-002** 全局统计支持按植物和年度筛选，展示出花梗及开花记录趋势。

**FR-STATS-003** 数据不足时说明原因，不显示误导性的 `0 天` 平均值。

**验收**：使用固定测试状态记录可手工复算全部结果；进行中记录和无效日期记录不混入已完成统计。

### 5.10 AI 小花灵

**FR-AI-001** 支持拍照或从相册选图识别植物，返回候选品种、置信度和简短依据；用户可确认候选或手动修改。

**FR-AI-002** 支持通用养护文字问答。

**FR-AI-003** 用户可主动选择一株植物作为上下文，发送其必要资料、当前状态和近期养护摘要；未选择时不得上传全部花园数据。

**FR-AI-004** 支持订单 OCR 文本增强解析，复用订单确认页。

**FR-AI-005** AI 接口与具体厂商解耦，首版提供通用适配层、开发 Mock 和一种可配置的兼容 HTTP 实现。

**FR-AI-006** 未配置服务、无网络、超时、限流或返回格式错误时提供可理解的错误和重试，不影响本地功能。

**FR-AI-007** 首次上传图片或植物上下文前展示隐私说明；API 凭据不得写入日志、备份或代码仓库。

**验收**：切换 Provider 不需要修改业务页面；Mock 可完成全部 UI 测试；真实服务通过契约测试后才可发布。AI 回答需提示仅供参考，不将病虫害判断描述为确定诊断。

### 5.11 设置、备份与导出

**FR-DATA-001** 设置页包含通知、自定义养护类型、自定义生长状态、AI 服务、备份恢复、CSV 导出和隐私说明。

**FR-DATA-002** 备份包含全部业务数据、照片和 manifest 版本信息，不包含 API Key 或系统通知标识。

**FR-DATA-003** 恢复前校验文件及版本、展示内容摘要，并在替换当前数据前二次确认和自动生成安全备份。

**FR-DATA-004** 首版恢复采用“安全备份后整体替换”，不做跨备份智能合并。

**FR-DATA-005** 支持导出植物 CSV 和账本 CSV，使用 UTF-8 编码并正确处理逗号、引号和换行。

**FR-DATA-006** 清空数据必须二次确认；操作完成后回到空花房引导页。

**验收**：备份—清空—恢复后，档案、照片、状态、日志、库存和账目一致；损坏或不兼容文件不得破坏现有数据。

## 6. 非功能需求

### 6.1 可用性与无障碍

- 主要触控区域不小于 44×44 pt，核心新增流程不超过必要步骤。
- 支持 Dynamic Type；文字放大后核心按钮和金额不可被截断。
- 正文及关键数据对比度至少 4.5:1；柔金色不得作为浅底上的小字号正文颜色。
- 图标按钮提供无障碍标签；减少动态效果开启时弱化阴影动画和过渡。
- 所有列表提供加载、空、错误和离线状态，不仅依赖颜色表达状态。

### 6.2 性能与容量

- 常规页面交互保持流畅，植物卡片使用缩略图，不在列表加载原图。
- 首版以 1,000 株植物、10,000 条日志、20,000 张照片为容量设计目标。
- 图片写入采用唯一文件名和相对路径，原图与缩略图分离。
- AI 请求可取消，页面退出后不得继续更新已销毁状态。

### 6.3 数据可靠性与隐私

- 多步写入必须保证事务一致性，避免植物已创建而自动日志/账目半完成。
- 数据模型具备稳定 UUID、创建/更新时间及 schema 版本，为同步和迁移预留能力。
- 不接入第三方行为分析 SDK；首版不采集使用行为。
- 相册、相机和通知均按实际使用时机申请权限，拒绝后提供替代路径。
- 敏感网络错误日志不得包含图片、完整植物上下文、API Key 或请求头。

## 7. 首版端到端验收场景

1. 手动新增植物并开启采购账目，设置封面，验证默认状态、分类、陪伴天数及关联采购支出。
2. 从订单截图导入，修正识别字段，确认后同时生成植物、日志和采购账目。
3. 将植物从养叶养根切换到出花梗，再到开花和养叶养根，验证历史、天数和统计。
4. 在花房长按并选择多株植物批量浇水，生成独立养护记录和日志，并自动完成各植物对应的周期待办。
5. 添加带多张照片的手动日志，检查列表缩略图与数量，进入日志详情全屏查看，再将其中一张设为封面。
6. 新增植料并调整至低库存，验证提醒；开关补光灯仅改变本地状态。
7. 手动记账并关联退款，验证总投入、分类汇总和月度筛选。
8. 使用 AI Mock 完成识别、订单解析和带单株上下文问答，并模拟失败重试。
9. 导出 CSV，验证中文及特殊字符；完成全量备份、清空和恢复。
10. 在拒绝相册/相机/通知权限和无网络情况下，验证核心记录仍可使用。
11. 从植物详情创建并修改每 N 天/周/月/年周期，在日历完成待办或手动记录对应养护，验证下一次待办、当前养护状态及历史记录。

- 本文件第 7 节场景全部通过。

- 完成隐私权限文案、AI 服务配置指引和数据备份说明。
- TestFlight 测试无阻断级崩溃、数据丢失或账目错误。
